# Калькулятор стоимости окраски автомобиля

Учебный проект для практической работы № 4 по Git и удалённым репозиториям.
Работа выполняется индивидуально, так как другие участники не назначены.

Все цены указаны в рублях. Базовая стоимость — 12 000 рублей за деталь.
Формула: базовая цена × коэффициент детали × коэффициент цвета.

## Запуск

Требуется Python 3.9 или новее, дополнительные библиотеки не нужны.

```text
python main.py
python -m unittest -v
```

Пример: передняя дверь и серый металлик: 12 000 × 1,2 × 1,3 = 18 720 руб.

Названия вводятся по списку; регистр и буквы «е» и «ё» не влияют на выбор.
